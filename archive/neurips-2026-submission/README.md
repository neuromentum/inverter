# Original NeurIPS 2026 submission code

[`code.zip`](code.zip) is an unchanged copy of the code bundle submitted with the
original paper, *Neuro-Inspired Inverse Learning for Planning and Control*.

The bundle includes core models, training and deployment code, and configurations
for Maze2D, AntMaze, AntMan, and quantum gate synthesis. Its internal
`code/README.md` describes the contents and machine-path placeholders.

The original bundle intentionally excludes D4RL evaluation harnesses, CORL
baselines, and figure, table, and analysis scripts. For the maintained setup and
evaluation workflow, start with the [Maze2D U-Maze tutorial](../../examples/maze2d_umaze/README.md).

This archive preserves the original submission snapshot and is separate from the
subsequent rebuttal and camera-ready work.
